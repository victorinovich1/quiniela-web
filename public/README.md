# Archivos de Iconos Requeridos

Para que la identidad visual funcione correctamente, coloca estos archivos en `public/`:

## Archivos Necesarios

1. **favicon.ico** (16x16 o 32x32)
   - Ícono clásico del navegador
   - Formato: ICO

2. **icon.png** (512x512)
   - Ícono principal de la PWA
   - Formato: PNG
   - Tamaño exacto: 512x512 píxeles

3. **apple-touch-icon.png** (180x180)
   - Ícono para dispositivos Apple (iPhone/iPad)
   - Formato: PNG
   - Tamaño exacto: 180x180 píxeles

## Configuración Actual

- ✅ `manifest.json` configurado
- ✅ `app/layout.tsx` con metadata completo
- ✅ PWA configurada como standalone
- ⚠️ **Faltan archivos de imagen**
