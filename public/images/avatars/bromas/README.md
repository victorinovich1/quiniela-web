# Avatares de Broma (Castigos)

Coloca aquí 10 imágenes numeradas del 1 al 10:

- `1.png`
- `2.png`
- ...
- `10.png`

El Rey (puesto #1) puede asignar estos avatares como "castigo" a otros usuarios.
Los castigos se limpian automáticamente cuando el próximo partido entra en vivo.

## Formato

- **Tamaño:** 256x256px
- **Formato:** PNG con transparencia
- **Peso:** < 50KB

## Sugerencias

Usa imágenes graciosas, payasos, memes, etc.
